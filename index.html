    White-label мобільний застосунок для клієнтів сервісної мережі

    Один код на всіх клієнтів бізнесу: брендування з конфігу, окремий піддомен і база на кожного. Облікова система бізнесу — зовнішнє API, в яке застосунок не втручається: уся логіка покупки, оплати й сповіщень живе на власному сервері.

    Vue 3IonicCapacitorTypeScriptFastifySQLiteFCMDockerCaddyCI

    Вхід і акаунт

    • Одноразовий код по SMS або Viber з автопідстановкою на Android, email і пароль, вхід через Google
    • Біометрія при запуску, перевірка дублів при реєстрації
    • Сімейні картки: одна людина керує замовленнями родини
    • Видалення акаунта у два кроки

    Покупка й оплата

    • Каталог із категоріями, акціями й крос-продажем у кошику
    • Промокоди та списання бонусів через калькулятор облікової системи
    • Онлайн-оплата з підписом на сервері, підтвердження вебхуком і опитуванням статусу
    • Чернетка замовлення, холд на N днів, «оплата на місці», повтор оплати, яка не вдалася
    • Полегшений розрахунок: 9–14 → 4 запити до зовнішнього API

    Сповіщення

    • Пуші про готовність, оплату й нагадування про покинутий кошик (не частіше разу на день)
    • Тихі години, розсилки з адмінки, вхідні в застосунку
    • Фоновий спостерігач за статусами з посторінковим опитуванням API

    Документи

    • Підписання документів у застосунку: ключ пристрою + біометрія, запасний варіант — код по SMS чи email
    • Перевірка ключа пристрою на сервері, штамп підпису в PDF, файл прикріплюється до картки клієнта

    Адмінка

    • Акції, розсилки, категорії каталогу, документи
    • Налаштування під кожного клієнта бізнесу, увімкнення функцій окремо

    Інфраструктура й безпека

    • Docker Compose + Caddy, скрипти оновлення, відкату, бекапу й відновлення з перевіркою
    • CI: демо оновлюється автоматично, бойові середовища — за захищеним тегом
    • Android-збірка однією командою, iOS через хмарну збірку без Mac
    • Перевірка цілісності застосунку, обмеження частоти запитів, маскування персональних даних у логах, політика зберігання даних
    • /health і watchdog з алертами в Telegram

    255 тестових файлів (unit + інтеграційні) і автоматичний UX-обхід у браузері. Розроблено з Claude Code приблизно за три тижні до тестової збірки в магазині застосунків.

    Що робить
    • Краулер із набором SEO-перевірок запускається щотижня; безпечні виправлення (meta description, SEO title) застосовуються через WP REST, решта сортується в ручну чергу.

    Bitrix24 RESTTelegram Bot APILLMNode.js
    Задача
    Задачі, згадки й повідомлення розкидані між CRM, поштою та чатами; власник пропускає важливе.
    Що зроблено
    Усе нове з CRM приходить у бота з кнопками дій, є відкладена публікація. Черга AI-виконавця: агент готує роботу в ізольованому середовищі, власник переглядає й затверджує в боті. Логіку видно в демо вище.

    Що робить

    • Пересланий у бота текст ніколи не виконується як команда, лише зберігається як матеріал — захист від prompt injection.

    Реклама, сайт, боти й CRM в одному потоці

    Реєстрація на вебінари: реклама → бот → CRM

    PHPWP-cronMeta Graph APIBot API
    Що робить
    • Ліди з рекламних форм і форм сайту автоматично реєструються на вебінар; зіставлення «форма → кімната» налаштовується в адмінці без коду.
    • Нагадування по email і в Telegram-боті; реєстрація через бота за deep link працює навіть без email, на десктопі — QR-код.
    • Усі ліди потрапляють у CRM.
    Результат
    75 реєстрацій на перший вебінар, 79 з 79 тестів рушія.
    • Інцидент зі спамом у формах: 1 593 сміттєві ліди за 2,5 години; сканер заблоковано, 1 621 з 1 623 лідів перемічено в CRM через API.
    • Аудит якості лідів з реклами: 8% кваліфікованих і жодної оплати; нова форма з питанням-фільтром і нове таргетування.
    • Аналітика лідогенерації через REST API CRM: динаміка рік до року з відсіюванням «шуму» від масових заходів.
    • GA4: окрема група каналів для трафіку з AI-асистентів через Admin API.
    • Монітор нормативних змін: кілька разів на день перевіряє джерела, фільтрує за темами й надсилає дайджест у Telegram.
